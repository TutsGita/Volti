# Volti 0.6.0

- A new, resizable panel. Every device uses the same card with its level, battery bar, connection, last reading and remaining time. Click a card to change tray visibility, alert thresholds or its name.
- A summary line counts devices and shows the lowest level. Devices can be sorted by battery or name.
- Settings grouped into General, Language, Devices and About, with a manual update check.
- Theme previews with each palette's battery colours, keyboard shortcuts (F5, Ctrl+1 to Ctrl+3, F2) and visible focus.
- The tray menu lists all readings, and the hover preview shows remaining time.
- Internal restructuring into shared, monitor and panel code, translations in JSON files, and automated parser checks.
